# 하루에 하루

> 스토리형 미스터리 퍼즐 어드벤처 게임

<img width="14" src="https://skillicons.dev/icons?i=gamemakerstudio" alt="gamemakerstudio2" /> GameMakerStudio2

<br/>

## 📝 프로젝트 소개

기초 게임 개발 수업 과제로 제작된 탑다운 뷰 게임 입니다.


플레이어는 교내를 탐색하며 아이템을 수집하고, 다양한 이벤트와 미니 게임을 해결하면서 이야기를 진행합니다.

<br/>

## 🎮 주요 기능

- **맵 탐색** — 교내의 여러 장소를 이동하며 단서와 상호작용 요소를 탐색합니다.
- **아이템 수집** — 진행에 필요한 열쇠와 아이템을 획득하고 사용합니다.
- **퍼즐 및 미니 게임** — 장소별 퍼즐과 미니 게임을 해결해 다음 이벤트를 진행합니다.
- **스토리 이벤트** — 플레이어의 진행 상태에 따라 이벤트가 순차적으로 발생합니다.
- **저장 및 이어하기** — 마지막 위치, 획득 아이템, 이벤트 진행 상태를 저장하고 불러옵니다.
- **처음부터 시작하기** — 기존 저장 데이터를 초기화하고 게임을 처음부터 다시 시작할 수 있습니다.

<br/>

## ⚙️ 구현 내용

### 게임 상태 관리

- 글로벌 변수를 이용해 플레이어의 위치, 획득 아이템, 이벤트 진행 상태를 관리했습니다.
- 게임 시작 시 필요한 상태를 `room_init`에서 초기화했습니다.

### 저장 시스템

- 게임 데이터를 `save.ini` 파일로 저장하도록 구현했습니다.
- `START` 선택 시 마지막 위치와 아이템, 이벤트 진행 상태를 불러옵니다.
- `RESTART` 선택 시 저장 데이터를 초기화하고 게임을 처음부터 시작합니다.

### 이벤트 진행

- 아이템 획득 여부와 이벤트 진행 상태에 따라 대사 및 상호작용 결과가 달라지도록 구현했습니다.
- 미니 게임 완료 여부를 다음 스토리 이벤트와 연결했습니다.
